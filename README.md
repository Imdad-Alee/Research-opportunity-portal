# Research Opportunity Portal

A full-stack web application for managing university research opportunities. Faculty members can post, view, update, and delete research opportunities through a simple web interface.

Built as Assignment 1 for the Computer Networks course.

## 🎯 Features

- **Backend REST API** with full CRUD operations
- **MySQL database** for persistent storage
- **Frontend** with live data from the API (no hard-coded data)
- **Input validation** on both frontend and backend
- **Proper HTTP status codes** (200, 201, 400, 404, 500)

## 🛠️ Technologies Used

| Layer | Technology |
|-------|------------|
| Backend | Node.js + Express |
| Database | MySQL (via XAMPP) |
| Frontend | HTML5, CSS3 (Bootstrap 5), Vanilla JavaScript |
| API Testing | Postman |

## 📋 Prerequisites

- Node.js (v18 or higher)
- XAMPP (for MySQL) — or any MySQL 5.7+ server
- Python 3 (for serving the frontend)
- Postman (for API testing — optional)
